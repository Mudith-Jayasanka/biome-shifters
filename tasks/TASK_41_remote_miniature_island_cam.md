# Task 41: Remote Miniature Island Cam & Viewport Snooper (Demand-Driven Architecture)

## Status: `DONE`

## Goal
Enable the Host to inspect live, on-demand satellite snapshots (64×64 pixel resolution) of any contributor island directly inside the Host Cluster Dashboard, with a demand-driven polling mechanism ensuring **zero bandwidth consumption** when the camera is not actively being viewed.

---

## Context & Architecture Evolution
Since Task 41 was initially drafted, our distributed cluster architecture has significantly evolved:
1. **Multi-Island Contributor Nodes (Task 28–30)**: Contributors run 1–8 cores with independent island IDs. The camera snooper must be selectable per-island (e.g. Island 9, Island 10), not tied to whole nodes.
2. **Demand-Driven Transmission (Zero Idle Bandwidth)**: Contributors must **never** send snapshots in regular background heartbeats when nobody is watching. Snapshots are generated by workers and transmitted over LAN **only** while the Host actively has the Snooper modal open for that specific island.
3. **Zero-Render Screensaver Synergy (Task 37)**: When a contributor machine has visuals muted (`isHidden: true`), the Web Worker continues simulating at full speed. The Snooper allows the Host to monitor remote visual ecology without burdening the contributor's GPU or main thread rendering.
4. **Radiation Palette & Glowing Border (Task 40)**: Irradiated islands use `IRRADIATED_BIOME_COLORS` (phosphor teal water, neon chartreuse and jade flora) and glowing borders. The satellite snapshot must respect `isRadiationMode` and render radioactive visuals when viewing irradiated islands.
5. **Agent Herd Visualization**: In addition to elevation and vegetation biomes, the worker superimposes living agent locations as bright high-contrast dots, allowing the Host to observe herding, migration patterns, and population swarms from orbit.
6. **Headless Worker Purity (Golden Lesson #8)**: The worker generates a pure flat TypedArray `Uint8ClampedArray` (zero DOM/Canvas dependencies) and transfers it via zero-copy `postMessage`. The contributor main thread converts it into a tiny WebP/JPEG data URL (~1 KB per frame).

## Detailed Specification

### 1. Backend: `server.py`
- In `ClusterManager`:
  - `cls.snooper_watch = {'islandId': None, 'expiresAt': 0.0}`
  - `cls.island_snapshots = {}`
  - Method `ClusterManager.set_snooper_watch(cls, island_id: int, duration_sec: float = 4.0) -> dict`:
    - Sets `cls.snooper_watch = {'islandId': int(island_id), 'expiresAt': time.time() + duration_sec}`
  - Method `ClusterManager.clear_snooper_watch(cls) -> dict`:
    - Sets `cls.snooper_watch = {'islandId': None, 'expiresAt': 0.0}`
  - Method `ClusterManager.store_snapshot(cls, island_id: int, snapshot_data: dict) -> dict`:
    - Saves snapshot into `cls.island_snapshots[island_id]` with timestamp, tick, pop, and `isRadiationMode`.
  - In `heartbeat()` response:
    - If `cls.snooper_watch['islandId'] is not None and time.time() < cls.snooper_watch['expiresAt']`:
      - If `snooper_watch['islandId']` is in this node's `islandIds`:
        - Include `'requestedSnapshotIsland': cls.snooper_watch['islandId']` in `globalState`.
      - Else:
        - `'requestedSnapshotIsland': None`
    - Else:
      - `'requestedSnapshotIsland': None`
  - Route `POST /api/cluster/snooper/watch`:
    - `{ islandId, duration }` -> sets snooper watch.
  - Route `POST /api/cluster/snooper/stop`:
    - Clears snooper watch.
  - Route `POST /api/cluster/island/snapshot`:
    - Accepts `{ islandId, dataUrl, tick, population, isRadiationMode }` and stores in `ClusterManager`.
  - Route `GET /api/cluster/island/snapshot?islandId=X`:
    - Returns cached snapshot record or 404.

### 2. Web Worker: `js/workers/island.worker.js`
- Function `generateSnapshot(targetWidth = 64, targetHeight = 64)`:
  - World grid is `CONFIG.GRID_WIDTH x CONFIG.GRID_HEIGHT` (128×128).
  - Scale factor = 2.
  - Create `pixels = new Uint8ClampedArray(targetWidth * targetHeight * 4)`.
  - Palette: `const palette = simulation.isRadiationMode ? IRRADIATED_BIOME_COLORS : BIOME_COLORS;`
  - Iterate `y` (0..63) and `x` (0..63):
    - World cell `wx = x * 2`, `wy = y * 2`.
    - Index `wi = wy * 128 + wx`.
    - Biome classification: `classifyBiome(grid.elevation[wi], grid.water[wi], grid.moisture[wi], grid.biomass[wi])`.
    - Get RGB from `palette[biome]`.
    - Write into `pixels[pxIdx + 0..2] = [r, g, b]`, `pixels[pxIdx + 3] = 255`.
  - Superimpose living agents:
    - For each agent in `simulation.agents` (if not dead):
      - `sx = Math.min(63, Math.max(0, Math.floor(agent.x / 2)))`
      - `sy = Math.min(63, Math.max(0, Math.floor(agent.y / 2)))`
      - `pi = (sy * 64 + sx) * 4`
      - Write bright white/yellow agent indicator: `pixels[pi..pi+2] = [255, 255, 230]`.
  - Post back:
    - `self.postMessage({ type: 'SNAPSHOT_READY', islandId, width: targetWidth, height: targetHeight, pixels: pixels.buffer, tick: simulation.tick, population: simulation.agents.filter(a => !a.isDead).length, isRadiationMode: simulation.isRadiationMode }, [pixels.buffer])`.
- Handle worker message:
  - `case 'REQUEST_SNAPSHOT'`:
    - Trigger `generateSnapshot(msg.width || 64, msg.height || 64)`.
  - Handle worker message:
    - `case 'REQUEST_SNAPSHOT'`:
      - Trigger `generateSnapshot(msg.width || 64, msg.height || 64)`.

### 3. Island Manager: `js/island-manager.js`
- Maintain `this.cachedSnapshots = new Map();`
- Add offscreen thumbnail canvas helper:
  - `this.snapshotCanvas = typeof document !== 'undefined' ? document.createElement('canvas') : null;`
- On worker message `'SNAPSHOT_READY'`:
  - Convert `pixels` to `ImageData`.
  - Draw to 64×64 offscreen canvas and call `canvas.toDataURL('image/jpeg', 0.6)`.
  - Cache `{ dataUrl, tick, population, isRadiationMode, timestamp: Date.now() }`.
  - If a snapshot callback or event is registered, notify listeners.
- Add method `requestSnapshot(islandId, width = 64, height = 64)`:
  - Sends `{ type: 'REQUEST_SNAPSHOT', islandId, width, height }` to worker.

### 4. Cluster Client: `js/cluster-client.js`
- In `sendHeartbeat()`:
  - Check `data.globalState.requestedSnapshotIsland`.
  - If `requestedSnapshotIsland` is in local `islandIds`:
    - Call `this.islandManager.requestSnapshot(requestedSnapshotIsland)`.
    - When snapshot is ready, immediately dispatch `POST /api/cluster/island/snapshot` with `{ islandId, dataUrl, tick, population, isRadiationMode }`.
- Host snooper methods:
  - `async startWatchingIsland(islandId)`: calls `POST /api/cluster/snooper/watch` with `{ islandId }`.
  - `async stopWatchingIsland()`: calls `POST /api/cluster/snooper/stop`.
  - `async fetchIslandSnapshot(islandId)`: calls `GET /api/cluster/island/snapshot?islandId=X`.

### 5. UI & Styling: `index.html`, `style.css`, `js/main.js`
- Add `#modal-island-cam` modal dialog:
  - Crisp retro 256×256 canvas or `<img>` with `image-rendering: pixelated;` displaying the 64×64 satellite feed.
  - Animated cybernetic radar scanline sweep across the viewport.
  - Glowing emerald border and `☢️ HIGH RADIATION LAB` badge when `isRadiationMode` is true.
  - Telemetry grid: Island ID, Machine IP, Ticks, Gen, Population, TPS.
  - Controls: `[ ☢️ Mutate / Restore ]`, `[ 🔄 Refresh ]`, `[ ✕ Close ]`.
- In Cluster Nodes table:
  - Each island pill displays a small `📹` icon button or clicking opens the Snooper.
- In `main.js`:
  - `openIslandCam(islandId)`:
    - Sets up 1.5s interval calling `clusterClient.startWatchingIsland(islandId)` and updating image.
    - If viewing a local Host island, fetches directly from local `islandManager.requestSnapshot()` without LAN HTTP.
  - `closeIslandCam()`:
    - Clears interval, calls `clusterClient.stopWatchingIsland()`, ensuring LAN bandwidth immediately stops.
